# @tapthrough/core

The parts of Tapthrough's SDKs that don't depend on a platform: the launch sequence, reports, the review
checklist and feature-flag overrides.

You don't install this directly. It comes with
[`@tapthrough/expo`](https://www.npmjs.com/package/@tapthrough/expo) for Expo apps and
[`@tapthrough/next`](https://www.npmjs.com/package/@tapthrough/next) for Next.js apps.

Start at <https://github.com/tapthrough/tapthrough>.
